Price API Documentation

价格管理接口文档

认证

需要认证的接口必须在请求头中包含 API Key：

X-API-Key: your-api-key

接口列表

GET /health 无需认证

健康检查接口，返回服务状态和当前价格数量。

响应示例

{ "status": "ok", "prices": 5 }
GET /api/prices 需要认证

获取所有已存储的价格数据。

响应示例

{ "count": 2, "prices": [ { "base_token": "0x...", "quote_token": "0x...", "base_decimals": 18, "quote_decimals": 6, "bids": [[1.0, 100], [0.99, 200]], "asks": [[1.01, 100], [1.02, 200]] } ] }
GET /api/price/history 需要认证

获取价格更新历史记录。

查询参数

参数 类型 说明
limit integer 可选 返回记录数量，默认 100

请求示例

GET /api/price/history?limit=50

响应示例

{ "count": 50, "history": [...] }
POST /api/price 需要认证

批量更新价格数据。

请求体参数

参数 类型 说明
levels array 必填 价格层级数组
operator string 可选 操作者标识

Level 对象结构

字段 类型 说明
base_token string 必填 基础代币地址
quote_token string 必填 报价代币地址
base_decimals integer 必填 基础代币精度
quote_decimals integer 必填 报价代币精度
bids array 必填 买单 [[价格, 数量], ...]
asks array 必填 卖单 [[价格, 数量], ...]

请求示例

{ "operator": "admin", "levels": [ { "base_token": "0x1234...abcd", "quote_token": "0x5678...efgh", "base_decimals": 18, "quote_decimals": 6, "bids": [[1.0, 100], [0.99, 200], [0.98, 300]], "asks": [[1.01, 100], [1.02, 200], [1.03, 300]] } ] }

响应示例

{ "success": true, "count": 1, "levels": [...] }

错误响应

// 401 Unauthorized {"error": "Unauthorized"} // 400 Bad Request {"error": "levels array is required"} {"error": "level 0: base_token and quote_token are required"} {"error": "level 0: invalid bid at index 0: price and amount must be positive"}

cURL 示例

健康检查

curl http://localhost:8080/health

获取价格

curl -H "X-API-Key: your-key" http://localhost:8080/api/prices

获取历史

curl -H "X-API-Key: your-key" "http://localhost:8080/api/price/history?limit=50"

更新价格

curl -X POST http://localhost:8080/api/price \ -H "Content-Type: application/json" \ -H "X-API-Key: your-key" \ -d '{ "operator": "admin", "levels": [{ "base_token": "0x1234", "quote_token": "0x5678", "base_decimals": 18, "quote_decimals": 6, "bids": [[1.0, 100]], "asks": [[1.01, 100]] }] }'
